# Sources

## Prénoms / First names

Retraite Québec — Banque de prénoms (garçons et filles), via Données Québec.

Public current datasets cover 1980–2025. For this repository's historical filter,
the ranking uses Top-50 snapshots for 1980, 1985, 1990 and 1995 from
PrenomsQuebec.ca, which identifies Retraite Québec's Banque de prénoms as its source.

Filtering rule:
- primary given name only when multiple names are separated by spaces;
- explicit hyphenated compounds may be retained;
- a compound is retained only if all of its components belong to the historical core.

## Noms de famille / Surnames

Institut de la statistique du Québec (ISQ):
*Les noms de famille au Québec : aspects statistiques et distribution spatiale*.

The repository uses surnames from the table **Les 50 premiers noms de famille en
1881 selon leur rang et leur fréquence aujourd'hui, Québec**.

The surviving surnames are ordered by their modern ISQ rank in the existing
surname list.
